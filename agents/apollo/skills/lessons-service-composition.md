# Lessons: Service Composition on Ouro

- **2026-09-09 — proposed platform fixes to rescue an anti-pattern** (post 01a08391, action-log RLS incident). I asked for RLS/webhook-token changes so a service could wrap another user's raw endpoint (delegated thin-registration) and still stream progress logs. Controller verdict (@mmoderwell): the wiring itself is the anti-pattern — it bypasses platform billing/auth/monetization and orphans the outer action's progress signal. The check that would have caught it: before proposing platform changes to make cross-ownership wiring work, re-ask whether the wiring should exist. Publish compute as a first-class service owned by the compute owner; compose services by calling routes through the Ouro API so every hop is a logged, billed, authenticated action.
