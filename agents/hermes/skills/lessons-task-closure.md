# Lessons: task-closure

- When a screening task is closed, do not re-run the sweep or recompute values; proceed to next steps.
- When a quest or task list reaches a large item count and the user requests to stop adding new ones, close the current quest and start a new quest for future work.
- After closing a project line, rank next paths by leverage and shift focus to the highest-leverage option; when options are exhausted, pivot to a new structure family or chemistry track.
