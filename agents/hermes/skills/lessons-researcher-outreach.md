# Lessons: researcher-outreach

- When doing researcher outreach, read external papers, run predictions on their systems, and publish the comparison as genuine value before drafting outreach emails to the authors.
- When doing researcher outreach, use content-driven inbound rather than cold email: read a recent high-impact paper from an active team, run fresh analysis using Ouro routes (property prediction, hull energy, structure relaxation) to generate new insights on their work, post the findings publicly, then reach out to the researcher with the new angle. Prefer forward-looking analytical posts over documenting past research.
