# Lessons: collab spec freeze (nanziang/Apollo topology work)

- Frozen acceptance criteria authored jointly can be unsatisfiable against the actual structure if neither party probes them first. The amide-pi criterion (H...centroid 3.2-3.6 A, pointing deviation <30 deg) passed zero of 9 real arms - the 8 in-range contacts point ~144 deg away (edge-facing). Before freezing numeric geometry criteria, run a one-minute feasibility probe on the real coordinates and report the distribution.
- A spec's "template" values are not always authoritative: the frozen ins template showed 2 SYMM lines, but its own prose said generate symmetry from the CIF. The CIF (P2_1/c) has 3 non-identity ops; copying the template verbatim would have shipped a wrong symmetry group. Prefer the generative instruction over the illustrative example, and check every generated artifact against the source symmetry (count the operators).
- UNIT-line convention depends on what the file contains: a standalone node net (Co + pseudo-atoms) needs UNIT = pseudo-atom per-cell counts (ASU rows x multiplicity), not the full crystal composition. Mixing conventions (12 400 92 52 with only 29 ASU lines) is silently wrong in SHELX-family tools.

## 2026-09-02 — delivered artifact deviated from the frozen spec it cites
- The o delivery placed NP1 at the N4-to-phenyl-centroid MIDPOINT while the frozen spec (01a06161) says "N atom coordinates of the qualifying N-H arm". The pipeline docstring even said the right thing; the ins writer did otherwise. Check: every pseudo-atom line in a delivered ins must be re-derived against the spec's placement rule, line by line, before delivery. A cheap self-test exists and was missed: for a midpoint-encoded HB pseudo-atom pair, 2x|OP2 - NP1| must reproduce the reported D...A; it gave 4.123 A instead of 2.708 A.
- SHELX LATT sign is a symmetry statement, not a preference: N must be negative for non-centrosymmetric groups. Shipped LATT 1 for P4_1 3 2 (#213), which injects an inversion center (24 -> 48 ops) and silently breaks every UNIT count. Closure check that catches it: UNIT counts must close under the ops the LATT+SYMM set actually generates (CO1 orbit 12 + CO2 orbit 24 = 36 closed only at 24 ops).
