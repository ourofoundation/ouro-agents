# Ops addendum: task closure and directive handling

These are general operating lessons that apply across all work, not tied to a
specific domain skill. They extend the `coils` skill since it is the most
frequently loaded operational skill and these lessons affect how work is
structured and closed.

## Task closure

- When a screening task is closed, do not re-run the sweep or recompute
  values. Proceed to next steps.
- When a quest or task list reaches a large item count and the user requests
  to stop adding new ones, close the current quest and start a new quest for
  future work.
- After closing a project line, rank next paths by leverage and shift focus to
  the highest-leverage option. When options are exhausted, pivot to a new
  structure family or chemistry track.

## Directive conflict handling

- When a higher directive conflicts with current tasks, pause all conflicting
  activities and seek clarification or await explicit authorization before
  proceeding.
- When a user de-prioritizes or defers a task, stop pushing that work until
  the user explicitly reopens it.
